# Changelog

## 2.0.0

- Both color themes rebuilt from scratch: **Okto Dark** (ink-violet) and **Okto Light** (warm lilac), pink accent, expanded workbench and syntax coverage, semantic highlighting.
- New file icon theme: flat color tiles with white glyphs for 37 file types (added yaml, lock, env, test, license, zip, pdf, text).
- Color-coded folders with glyph badges (src, docs, test, assets, public, config, git, node_modules, scripts), closed and open.
- New extension icon and README previews.
- Theme files renamed to `okto-dark-color-theme.json` / `okto-light-color-theme.json`.
- Themes and icons are now generated by `scripts/generate_*.py`.
