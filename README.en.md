**Okto for VS Code is two color themes, file icons and color-coded folders.** The ink-violet **Okto Dark** and the warm lilac **Okto Light** with a pink accent, flat colorful icons for 37 file types and 10 kinds of folders, and detailed code highlighting. Not a single line of code in the extension — just color.

<summary><b>Feature details</b></summary>

### Themes

**Okto Dark** has a deep ink-violet background, light text and a pink accent `#FF7DB0` (cursor, active tab, current line number, badges). **Okto Light** is a warm lilac background with a `#D62F78` accent and a violet status bar. Both themes style the whole VS Code interface: panels, tabs, lists, terminal, diff, Git, debugger, rainbow brackets and symbol icons.

### Code highlighting

Semantic highlighting (`semanticHighlighting`) is on, backed by 30+ TextMate rules: keywords, strings, numbers, functions, types, parameters (italic), `this`/`self`, properties, decorators, HTML tags and attributes, CSS selectors and properties, JSON keys, Markdown headings and links, diff.

### File icons

37 flat tiles with a white glyph: Python, JavaScript, TypeScript, JSON, YAML, Markdown, HTML, CSS, SQL, Docker, Git, Rust, Go, Java, C, C++, C#, Ruby, PHP, Swift, Kotlin, Svelte, Vue and more. There are dedicated icons for lock files, `.env`, tests (`*.test.ts`, `*.spec.js`), licenses, archives, PDF and plain text.

### Color folders

`src`, `docs`, `test`, `assets`, `public`, `config` / `.vscode`, `.git` / `.github`, `node_modules`, `scripts` — each has its own color and a badge on the front, closed and open. All other folders are violet.

<summary><b>Installation</b></summary>

**From a `.vsix`** (recommended):

1. Download `okto-theme-*.vsix` from the [release page](https://github.com/sailxx/okto-vscode-theme/releases/latest).
2. Run `code --install-extension okto-theme-2.0.0.vsix` or open **Extensions → ⋯ → Install from VSIX…**.
3. Pick a color theme: `Ctrl + K`, then `Ctrl + T` — **Okto Dark** or **Okto Light**.
4. In the Command Palette (`Ctrl + Shift + P`) run **Preferences: File Icon Theme** and choose **Okto Icons**.
5. Then run **Preferences: Product Icon Theme** → **Okto Product Icons**.

**Manually (Windows):** clone the repository, create `local.okto-theme-2.0.0` in `%USERPROFILE%\.vscode\extensions` and copy `package.json`, `icon.png`, `icon.svg` and the `themes`, `fileicons`, `producticons` folders into it. Then restart VS Code (**Developer: Reload Window**).

The product icon theme replaces the built-in VS Code icons. Icons added by individual extensions are controlled by those extensions and may not be replaced by the theme.

<summary><b>Development</b></summary>

Themes, icons and README banners are generated by Python scripts; SVG and JSON files are not edited by hand:

```bash
pip install fonttools brotli
python3 scripts/generate_file_icons.py   # file and folder icons + fileicons/okto-icon-theme.json
python3 scripts/generate_themes.py       # themes/okto-dark|light-color-theme.json from two palettes
python3 scripts/generate_branding.py     # icon.svg
python3 scripts/build_readme.py          # README banners in both languages
npx vsce package                         # okto-theme-<version>.vsix
```

```
fileicons/        — file icon theme (okto-icon-theme.json, icons/*.svg)
themes/           — okto-dark-color-theme.json, okto-light-color-theme.json
producticons/     — product icon theme (okto-product-icons.woff font)
scripts/          — generators (theme palettes live in generate_themes.py)
assets/readme/    — README banners
```

The Golos Text and JetBrains Mono fonts (used for the banners) are distributed under the SIL Open Font License 1.1.
